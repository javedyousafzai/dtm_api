# IOM DTM API — Python Explorer

A Python toolkit for accessing and visualising displacement data from the [IOM Displacement Tracking Matrix (DTM) API](https://dtm.iom.int/) (v3).

---

## What is DTM?

The IOM Displacement Tracking Matrix (DTM) is a system that tracks and monitors displacement and population mobility around the world. This repo provides scripts and a Streamlit dashboard to query the DTM REST API and work with the resulting data in Python.
